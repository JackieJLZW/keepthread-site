KeepThread Quick Start Guide

Link your local Obsidian Vault once, sync conversations from ChatGPT, Gemini, Perplexity, DeepSeek, and Grok in one click—and edit your notes freely without ever losing your custom tags or [[backlinks]] on re-sync.

1. Get running in 30 seconds

1

Install & Pin Icon

Install KeepThread in Chrome or Microsoft Edge, click the top-right puzzle icon (Extensions), and pin KeepThread to your toolbar.

2

Link Obsidian Vault

Open the welcome screen (or Obsidian Vault tab) and select your local Vault folder once. KeepThread uses the browser File System Access API—zero local server setup.

3

1-Click In-Place Sync

Open any chat on ChatGPT, Gemini, Perplexity, DeepSeek, or Grok and click Sync to Vault (or press Alt+Shift+S). Existing tabs need one refresh after first install.

4

Search Offline Anytime

Press ⌘⇧K / Ctrl+Shift+K anywhere in your browser to search prompts, code blocks, and citations across all 5 AI platforms locally in IndexedDB.

3. How Lossless Sync protects your Obsidian notes

Edit your AI notes freely in Obsidian — re-syncing never destroys your work

Every note synced to your Vault includes invisible HTML markers (completely hidden in Obsidian Live Preview & Reading view). Whenever you continue a chat and click Update Obsidian Note In-Place, KeepThread reads your existing local file first and performs a lossless merge:

  • Custom YAML Properties & Tags: Any property you add in Obsidian (such as status, project, aliases, rating) and any extra tags are merged and preserved verbatim.
  • Top Notes Slot: Write summaries, highlights, or [[backlinks]] inside <!-- keepthread:notes:start --> … <!-- keepthread:notes:end --> (or anywhere above ## Prompt). KeepThread never touches it.
  • Bottom Follow-Up Sections: Anything you append below <!-- keepthread:transcript:end --> (such as tasks or reflections) is also kept intact at the bottom of the updated note.

5. Frequently Asked Questions

How can I verify KeepThread really has zero cloud servers?

Open Chrome/Edge DevTools → Network tab while syncing a conversation. Zero bytes leave your machine during extraction, Markdown conversion, local search, or Obsidian Vault file writes. The only optional outbound request is Pro license key verification directly with live.dodopayments.com—which never includes any chat text or URLs.

Why does Chrome ask for one click to re-grant Vault write permission after a browser restart?

That is a built-in Chromium security rule for the File System Access API: directory handles are saved permanently in IndexedDB, and after a full browser restart Chrome asks for one click ("Allow edit") before writing to disk again. Within the same browser session, every sync is completely 1-click.

What happens if ChatGPT, Gemini, Perplexity, DeepSeek, or Grok updates its page layout?

Open the License & Privacy tab inside KeepThread and click Copy DOM Outline. It generates a sanitized HTML tag skeleton containing zero chat text that you can email to support@jianlanzhiwei.com so we can ship an adapter patch rapidly.

How does the 3-device Lifetime Pro license work?

Pay once ($19 Early Bird via Dodo Payments) and receive a license key instantly by email. Activate it on up to 3 browsers/machines (for example: work Mac, personal laptop, and Edge). You can deactivate any device anytime inside KeepThread to free up its slot.
